# toreca-arb

カードラッシュ（販売）と晴れる屋2ネット買取（買取）の価格を30分おきに比べ、
「販売価格 < 買取価格 − 経費」になったカードをiPhone（ntfy）に通知する。購入は手動。

## 仕組み
- `monitor/run.py`：1回分の処理（GitHub Actions `monitor` が30分おきに実行）
- 晴れる屋2ネット買取：買取価格の高い順に上位ページを毎回取得
- カードラッシュ：販売価格の高い順の全件一覧を、前回の続きから10ページずつ巡回（5,000円以上は約55ページ＝約3時間で1周）
- カードの同一判定：収録弾コード＋カード番号＋レアリティ＋名前（＋PSA10かどうか）。状態B以下・ミラー・エラー品などは対象外
- 状態と履歴は `data` ブランチに保存（`detections.csv` が検知履歴）

## 通知
- 価格逆転：カード名・両店の価格・想定利益（タップでカードラッシュの商品ページ）
- 毎朝9時台：稼働報告（前日の取得成功／失敗ページ数・検知数）。**届かなければ監視が止まっている**
- 同じ店の取得に3回連続で失敗したら即時エラー通知

## 設定
`monitor/config.py`：通知条件（利益1,000円以上・利益率10%以上・販売5,000円以上）と送料・手数料の見積もり。

## 対象外にした店（2026年11月の調査）
遊々亭・カーナベル・ドラゴンスター・ラッシュメディア（カードラッシュの買取）は自動アクセスを拒否（403／Cloudflareの確認画面）。
